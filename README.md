## Projetos em destaque

### [AutoFlow](https://github.com/Yuri2332/AutoFlow)
MVP de automação visual para criar fluxos, executar ações e acompanhar cada etapa. Usa React e TypeScript na interface, Node.js na API e PostgreSQL ou SQLite para persistência.

### [EndoCare](https://github.com/Yuri2332/EndoCare2026)
Aplicação local com chat EndoBot, modelo Qwen executado pelo Ollama e integração com Supabase. O projeto também oferece voz opcional.

### [GameTracker](https://github.com/Yuri2332/GameTracker)
Central pessoal para organizar biblioteca de jogos, sessões, metas e atividade. Combina frontend React/Vite com API FastAPI e SQLAlchemy.

### [SecureScan](https://github.com/Yuri2332/SecureScan)
Ferramenta local de revisão defensiva para projetos que tenho autorização para analisar. Examina arquivos de forma controlada, sem executar os scripts enviados.

### [PC Monitor ESP32](https://github.com/Yuri2332/pc-monitor-esp32)
Monitor local com agente Python, painel web responsivo e firmware para ESP32-S3. O agente coleta métricas do computador e pode enviá-las ao dispositivo pela rede local ou USB.
